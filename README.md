# Ahmed Tarek Portfolio Website

This is a single-page portfolio website designed for GitHub Pages.

## Files

- `index.html` — the complete website.
- `assets/cv-job-matching-preview.png` — preview image for Project 2.

## Before publishing

The project buttons currently use these repository addresses:

- `https://github.com/AhmedTarekPortfolio/Excel-data-cleaning`
- `https://github.com/AhmedTarekPortfolio/CV-Remote-Job-Matching-Workflow`

If either repository has a different name, open `index.html` and replace only the matching link.

## Publish with GitHub Pages

1. Create a public GitHub repository named `AhmedTarekPortfolio.github.io`.
2. Upload everything inside this folder, including the `assets` folder.
3. Open the repository’s **Settings → Pages** section.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. After GitHub finishes publishing, open your GitHub Pages address.

## Add your real Excel screenshot later

The Excel project uses a clean built-in spreadsheet preview so the site works immediately. Later, you can replace that preview with your own screenshot by adding an image under `assets/` and changing the first project visual in `index.html`.
